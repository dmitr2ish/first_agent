# Документация Visa Research Workflow

Документация разделена по назначению и описывает только текущее устройство
проекта.

## [Обзор и руководство](OVERVIEW.md)

Для пользователя и разработчика, который впервые открывает репозиторий:
назначение системы, установка, интерактивный режим, benchmark, артефакты,
настройки и ограничения.

## [Дизайн и гарантии](DESIGN.md)

Объясняет, почему pipeline построен именно так: границы доверия, обязательное
получение evidence, контроль tool calls, правила цитирования, fail-closed
поведение, безопасность, изоляция сессий и воспроизводимость benchmark.

## [Архитектура](ARCHITECTURE.md)

Техническая карта кода: пакеты и зависимости, последовательность шести шагов,
контракты данных, SQLite/XLSX reporting, evidence record/replay и точки
расширения.

Короткая инструкция запуска и карта каталогов находятся в
[корневом README](../README.md).
